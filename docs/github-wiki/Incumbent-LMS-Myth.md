# The Incumbent LMS Myth (Moodle / Canvas vs Salama Shule)

A frequent evaluation objection is: *"Schools and universities already use Moodle or Google Classroom. Why do we need Salama Shule?"*

Traditional Learning Management Systems (LMS) were designed for Western institutions with continuous high-speed Wi-Fi and high-end laptops. In the Kenyan classroom context, they fail predictably:

### Comparison Table: Traditional LMS vs Salama Shule

| Metric | Traditional Moodle / Canvas | Salama Shule Engine |
| :--- | :--- | :--- |
| **Connectivity Requirement** | Continuous 3G/4G/Wi-Fi connection | **100% Offline Capable** (syncs upon pulse) |
| **Data Cost Per Module** | 15MB to 40MB | **Under 120 Kilobytes** (text-first) |
| **Network Drop Handling** | Session timeout (401/504) & lost answers | **Zero data loss** (queued in IndexedDB) |
| **Device Requirements** | Heavy RAM & modern storage | Runs smoothly on **1GB RAM Android 8+ phones** |
| **Lecturer Export** | Complex enterprise gradebooks | **One-click WhatsApp summary & CSV export** |
